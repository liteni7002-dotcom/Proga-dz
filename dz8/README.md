# Домашняя работа 8

## Постановка задачи

Внести изменения в Домашнее задание 10.

Реализовать обработку исключений. Генерировать и обрабатывать исключения минимум трех разных типов, одним из которых обязательно должно быть исключение-объект класса.

## Описание программы

При создании обычного кролика могут обрабатываться исключение возраста и исключение некорректного аргумента. При создании кролика убийцы в дополнение к вышеупомянутым обрабатываются исключения выхода за нижнюю и за верхнюю границы диапазона.
